# Лабораторна робота 2 Дискретна Математика

## Опис імплементації
У цій роботі реалізовано компілятор регулярних виразів
у недетермінований скінченний автомат (NFA) з використанням закономірності проектування станів.

### Реалізовані класи:
* **TerminationState**: Стан, що позначає успішне завершення розпізнавання рядка.
* **DotState**: Реалізує оператор `.`. У методі `check_self` завжди повертає `True`, тобто будь-який символ.
* **AsciiState**: Базовий стан для конкретних літер та цифр.
* **StarState (*)**: Стан для реалізації повторень від 0 до нескінченності.
* **PlusState (+)**: Стан для реалізації повторень від 1 до нескінченності.


Логіка перевірки базується на відстеженні множини 
активних станів одночасно, що дозволяє коректно обробляти 
недетерміновані переходи (наприклад, коли символ може одночасно 
задовольняти і повторення, і перехід до наступного етапу).

## Інструкція до запуску
Для запуску програми необхідно зайти в термінал і запустити даний файл main.py.

вводити наступне за вашим смаком і вибором

python regex_new.py --regex "a*4.+hi" --strings "aaaaaa4uhi" "4ohi" "a4++hi" "42+hi" "meow"

виведе десь таке:

Regex Pattern: a*4.+hi
------------------------------
'aaaaaa4uhi': True
'4ohi': True
'a4++hi': True
'42+hi': True
'meow': False

python regex_new.py --regex "b+c" --strings "bc" "bbbbc" "c" "abc"

Regex Pattern: b+c
------------------------------
'bc': True
'bbbbc': True
'c': False
'abc': False

python regex_new.py --regex "..*" --strings "a" "123" ""

Regex Pattern: ..*
------------------------------
'a': True
'123': True
'': False
